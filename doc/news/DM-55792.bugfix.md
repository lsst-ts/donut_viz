Fixed `NotImplementedError: memoryview: unsupported format 7w` when building the per-detector Zernike summary table in `PlotAOSTask`.

`np.unique` on an astropy `Column` used to return a `Column`, whose `.data` gives the underlying array. With NumPy >= 2.3 the new hash-based `unique` path re-wraps the result and astropy demotes it to a plain `ndarray`, where `.data` is the raw PEP 3118 buffer instead. Iterating that buffer fails for unicode dtypes. The `.data` access was unnecessary and has been removed.
